# Grill Me

Run the `grilling` Skill workflow.

If `grilling` is not available in the current agent, explain that dependency
instead of claiming the workflow ran.

For a confirmed software change, let `grilling` continue into its subordinate
specification, tracer-bullet TDD, verification, two-axis review, and commit flow.
Never let that flow override higher-priority governance or the user's current
explicit instructions.
